# Recording shortlist

A small practice and comparison set drawn from the [analysed collection](../research/music-analysis/tracks.csv), not a popularity ranking. The [Balfolk Database](https://balfolk-db.eu/view/) supplies broader repertoire and alternate recordings. A dance-compatible recording is not automatically a synchronized app preset; exact versions and phrase entries matter.

| Dance | Starting examples | Purpose / status |
| --- | --- | --- |
| Bourrée bancale | Accordzéâm — Allez, bourrés; AedO — Experior (Remix) | Existing selected practice passages; two-time bourrée music, not proof of one particular six-person choreography |
| Chapelloise | Accordzéâm — Jopelloise; Alambic — La Scoumoune | Complete local examples; no app synchronization map |
| Cercle circassien | Accordzéâm — Starwars; Alambic — Quadratures | Complete local examples; check whole figure-cycle phrasing before mapping |
| Branle de Noirmoutier | Arbadétorne — Les gens qui sont riches; Ciac Boum — Suite de Bransles | First is a complete local recording; second was a database preview only |
| Waltz | AedO — Lora Luna; Alambic — Lofoten Lights | Ordinary waltz examples; exclude odd-count variants from the shared three-count animation |
| Schottische | Accordzéâm — Hotel Califorgna and Jottish; Alambic — La Solitaire | Three contrasting accent patterns in the motion comparison page; not production maps |
| Mazurka | ba.fnu — Zabili; Naragonia — Alio; Brotto–Lopez — La Candèla | Contrasting layers and versions; Zabili's corrected pulse is about 95/minute; Alio's full analysed stream is the Boom bal compilation |
| Hanter-dro | ba.fnu with Yann-Fañch Kemener — Hanter dro; ARVEST — Kuzhet | Existing ba.fnu app passage plus a complete local comparison. Barray stays outside this recommended starting pair while its count rate is unresolved |

| Drumul Dracului | Żniwa — Drumul Draculi; Stary Olsa — Drumul Draculi | Existing variable-tempo passages and the first candidates for visual review |

## Direct sources and versions

- Existing synchronized recordings, passage boundaries and links: [music synchronization notes](music-sync.md).
- Accordzéâm — Jottish, on *Tapas*: [release track](https://music.amazon.ca/tracks/B09WJ7J5RH). The local analysed file is approximately 3:44; another upload need not share its timing.
- Alambic — La Solitaire, on *Tournée générale*: [release listing](https://www.e.leclerc/fp/tournee-generale-3521383405178). This is the French balfolk group, not the unrelated Scottish artist with the same name on Bandcamp.
- [ba.fnu — Zabili](https://bafnu.bandcamp.com/track/zabili-mazurka).
- [Alio on Boom bal Vol. 1](https://homerecordsbe.bandcamp.com/track/alio); [Naragonia's Tandem release](https://www.naragonia.com/shop/products/cd-tandem?variant=41847353671746). Keep these versions distinct.
- [Jonathan Gabay — Tzadik Katamar](https://musicfromisrael.bandcamp.com/track/tzadik-katamar); [Effi Netzer — Tzadik Katamar](https://music-from-israel.bandcamp.com/track/tzadik-katamar).
- [Żniwa — Dwa Żywioły](https://zniwaband.bandcamp.com/album/dwa-ywio-y); [Stary Olsa — Drumul Draculi](https://staryolsa.bandcamp.com/track/drumul-draculi-2).

Items without an exact public source link above refer to the identified local-library files in the CSV. No replacement upload was treated as audio-identical merely because its title matched.
